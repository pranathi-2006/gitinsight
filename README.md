**GitInsight**
GitInsight is a web application that analyzes GitHub repositories and provides useful insights like stars, forks, commits, and contributors 
in a simple and user-friendly interface.

**Features**
* Enter any GitHub repository URL
* View repository statistics (stars, forks, commits)
* Analyze contributors
* Clean and interactive UI
  
 **Tech Stack**
* Frontend: React.js
* Routing: React Router
* API: GitHub REST API
* Storage: LocalStorage
  
 **How to Run Locally**
```bash
git clone https://github.com/pranathi-2006/gitinsight.git
cd gitinsight
npm install
npm start
```
